# Claimo — Rebuilt From Scratch

An e-commerce consumer grievance assistance platform designed with a radically visual, interactive, minimal, and product-led aesthetic.

## Startup Integrity
- **Zero fake social proof**: No invented case counts, recovery crores, success percentages, or fake customer testimonials.
- **70% visual / 30% text**: Visual storytelling, interactive phone simulation, and kinetic typography.

## Key Sections & Features
1. **Full-Screen Hero**: Eyebrow badge, oversized typography with electric lime highlight, and video container (`/assets/hero-phone.mp4`) with an animated CSS fallback phone mockup.
2. **"When Shopping Goes Wrong"**: Animated order timeline concluding in a pulsing `REFUND REJECTED ✕` notification.
3. **"What's Gone Wrong?" Complaint Selector**: Horizontal draggable/scrollable category cards with custom animated SVGs and instant modal triggering.
4. **"Just Show Us What Happened" Phone Journey**: Giant interactive smartphone centerpiece with a 5-stage interactive dispute progression.
5. **"No More Chasing"**: Visual comparison between chaotic support loops and Claimo's organized resolution pathway.
6. **Early-Access Pricing**: 3 clean minimal tiers (Case Check ₹99, Resolution Assist ₹299, Concierge ₹799).
7. **"Why Claimo"**: Kinetic chaos badges collapsing into the glowing word `CLAIMO.`
8. **Final CTA & Direct Intake Modal**: Integrated multi-step grievance filing dialog.
9. **Regulatory Disclaimer**: Explicit independent grievance assistance disclosure.

## Quick Start
Open `index.html` directly in any modern browser or run:
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.
